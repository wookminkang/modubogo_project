# 원장 회신 화면(`/holiday/[company]/[month]`) — UX 점검

> 대상: 원장(고객)이 알림톡 "진료일정 회신하기"로 진입하는 **공개 회신 화면**
> 파일: `src/app/holiday/[company]/[month]/page.tsx`, `HolidayCheckForm.tsx`, `actions.ts`
> 작성 목적: 사용자(원장) 입장의 부족점을 정리. 심각도 ★(높음) 표기. **구현은 우선순위에 따라 별도 라운드.**

## 상세

### 1. ★ 재제출 인지 없음
- 현상: 재진입 시 기존 값은 채워지지만(`page.tsx`에서 `getHolidaySchedules` 병합), "이미 제출함 / 마지막 제출 시각" 안내가 없다. 원장이 "내가 전에 했나? 또 해야 하나?" 혼란.
- 근거: `HolidayCheckForm.tsx`에 제출 이력/상태 배지 없음. `holiday_submissions`에 제출 시각이 있는데 화면에 노출 안 함.
- 개선안: 상단에 "최근 회신: YYYY.MM.DD HH:mm · 수정하시려면 변경 후 다시 확인 완료" 배지. 최초 vs 수정 안내.

### 2. ★ 부분 저장 불가
- 현상: `allComplete`(모든 항목 완료)일 때만 "확인 완료" 활성(`HolidayCheckForm.tsx:182,383`). 공휴일이 여러 개인 달에 한 번에 다 못 채우면 아무것도 저장 못 함.
- 개선안: 항목별 저장 또는 "임시저장" 분리. 최소한 "지금까지 입력 저장" 허용.

### 3. ★ 시간 유효성 검증 없음
- 현상: `isItemComplete`는 값 존재 여부만 확인(`HolidayCheckForm.tsx:154-160`). 시작>종료, 점심이 진료시간 밖이어도 통과 → 잘못된 운영시간이 플랫폼에 반영될 위험.
- 개선안: `short_start < short_end`, `lunch_start < lunch_end`, 점심 ⊂ 진료시간 검증 + 인라인 에러.

### 4. 시간 옵션 하드코딩
- 현상: 진료 시작 08~13시, 종료 12~22시, 점심 11~15시(`buildTimes`, `START/END/LUNCH_OPTIONS` `HolidayCheckForm.tsx:46-51`). 심야·이른 진료·24시 병원 대응 불가.
- 개선안: 범위 확장 또는 자유 입력(스텝퍼). 최소 06~24시.

### 5. 이탈 경고 없음
- 현상: 입력 도중 새로고침/뒤로가기 시 경고 없음. 카카오 인앱 브라우저 특성상 실수 이탈 잦음.
- 개선안: 변경됨(dirty) 상태에서 `beforeunload` 경고.

### 6. 반복 입력 번거로움
- 현상: 공휴일마다 동일 진료시간을 매번 선택. 정상진료 09~18 + 점심 동일 패턴 반복.
- 개선안: "직전 항목과 동일 적용" / "전체 동일 적용" 버튼.

### 7. 월 캘린더 시각화 부재
- 현상: 공휴일 카드 세로 나열만. 어느 요일/주차인지 감이 약함.
- 개선안: 상단에 월 캘린더 썸네일(공휴일 하이라이트). (이번 라운드 임의 휴무 캘린더와 통합 가능)

### 8. 공휴일 없는 달 = 막다른 길
- 현상: "이번 달 공휴일이 없어요"만 뜨고 제출 버튼도 없음(`HolidayCheckForm.tsx:310-313`).
- 개선안: 이번 라운드 **임의 휴무 추가** 기능으로 이 경우에도 등록 가능해져 일부 해소.

### 9. 접근성
- 현상: 상태 선택이 `button`인데 `aria-pressed`/그룹 라벨 없음(`HolidayCheckForm.tsx:329-342`). 타임피커 Drawer도 라벨 보강 여지.
- 개선안: `role="radiogroup"` + `aria-pressed`, 포커스 가시성.

### 10. 에러 처리 약함
- 현상: 제출 실패 시 단순 텍스트(`HolidayCheckForm.tsx:372`). 이력 저장 실패는 조용히 무시(`actions.ts:50-53`, `console.error`만).
- 개선안: 재시도 버튼/토스트, 이력 실패 시 최소 경고.

### 11. 완료 화면 CTA 맥락
- 현상: 완료 후 "지난달 보고서 바로가기"(`HolidayCheckForm.tsx:262-269`). 원장에게 항상 유용하진 않음.
- 개선안: "회신 내용 다시 보기" 또는 닫기 중심. 보고서 링크는 보조.
